# Florida & Tennessee Land Prices Per Acre by County - Free Data

Free county-level land value data for all 67 Florida counties and all 95 Tennessee counties, compiled from public federal datasets by [Abundant Land Group](https://abundantlandgroup.com/).

## Full studies

- [Florida Land Prices Per Acre by County (2026)](https://abundantlandgroup.com/florida-land-prices-per-acre-2026)
- [Tennessee Land Prices Per Acre by County (2026)](https://abundantlandgroup.com/tennessee-land-prices-per-acre-2026)

## Files

| File | Contents |
| --- | --- |
| `fl_land_prices_per_acre_by_county.csv` | Florida, 67 counties: USDA NASS farmland value per acre (2017, 2022, % change, land in farms) and FHFA residential land / quarter-acre lot values (2012-2022) |
| `tn_land_prices_per_acre_by_county.csv` | Tennessee, 95 counties: same measures |
| `state_level_nass_land_values.csv` | State-level farm real estate, cropland and pasture values, 2021-2026 |

## Sources

- USDA NASS 2022 Census of Agriculture, Vol. 1 Ch. 2 County Table 8 (Quick Stats bulk file); 2017 Census of Agriculture
- USDA NASS Land Values 2026 Summary
- FHFA Working Paper 19-01, "The Price of Residential Land for Counties, ZIP Codes, and Census Tracts", v4.0 (June 2024)

Census values are farmer-reported market values of farmland including buildings, in nominal dollars. Counties marked `n/a` fall outside the FHFA annual county panel (insufficient appraisal sample).

Free to use with attribution to Abundant Land Group and the underlying federal sources.
